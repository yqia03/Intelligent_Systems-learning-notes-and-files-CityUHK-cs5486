给出一张模型对照表：模型解决什么问题、输入与输出、学习方式、关键机制、训练哪些参数、目标与约束、求解方式、适用条件、主要限制及中英文关键词。区分模型（例如 MLP）与训练算法（例如 BP），不能把所有名称都当同类模型。
正文沿课程顺序组织，避免把基础理解与计算完全割裂成两套重复教材；每个知识点清楚标记“理解”“计算”或“两者”。末尾提供分成 A 基础理解与简答、B 建模推导与计算的自测练习。LS-SVM 应有连续完整专题，不能只在模型表占一行或给最终矩阵。

每个知识点都包括：
1. 直接可见的精炼复习：核心意思、为什么需要、适用条件、相关模型辨析。
2. 关键公式与符号说明（确有公式时）：清楚说明输入/输出维度、参数和约定，不只列孤立公式。
3. 一至数个有针对性的常见混淆或计算易错点；不把自己的推测写成老师强调。
4. 至少一个默认收起的例题。用原生 details/summary；summary 写明题目类型与情境，展开后显示完整题目、思路、步骤与答案。需要自测时，可在例题内另设“查看解析”的折叠块。不要将知识点正文整体隐藏。
5. “没理解？回到完整笔记”的具体小节链接，以及原资料文件名/实际页码。不能只链接周首页。

概念型知识点用任务判断、解释、比较或反例作例题，不硬编算术；计算型知识点必须给出可手算的小规模数据和关键中间步骤。
对于多个紧密相关的点可以共用一组分问，但每个独立知识点须在索引、例题和原笔记链接中有明确对应，不能用一题泛泛覆盖整章。

先对照真实教材和主课件建立覆盖表，再写正文。以下为最低主干，不是允许漏掉范围内其他相关概念的理由。

第 03 周：ADALINE 与感知机的区别、线性残差、LMS、online/batch、MLP 和 XOR 表示、可微激活、前向传播、链式法则、BP 输出层/隐藏层梯度、momentum、表示/优化/泛化及过拟合。给出小型网络的一次完整前向、反向与更新；统一损失的 1/2 因子、偏置符号和更新顺序。

第 04 周：RBF 网络、中心/宽度/输出权重、显式映射、φ 可分性、FLN、ELM、SVM 最大间隔、primal/dual/KKT、支持向量和预测。覆盖 RBF 特征计算、简单输出求解、函数/几何间隔、一个小型硬间隔 SVM、KKT 检验和新点预测。FLN/ELM 重点是机制与参数角色，课程未要求的高难度求解不强加。

第 05 周：软间隔及 ξ、C 的作用、核函数和 Gram 矩阵、核宽度、核分类、SVR 的 ε 管道/两类松弛/预测/偏置、LS-SVM 的平方误差/等式约束/线性系统、分类与回归形式区别、稀疏与稠密、模型选择和数据泄漏。
覆盖软间隔状态判定、核值和显式特征、SVR 残差/损失/松弛、给定合规系数求预测与 b。LS-SVM 按下方最新重点完成“从模型到求解”的全链条，不能只练代入现成矩阵。新增资料的疑似笔误不得带进复习题；对于 ε=0、没有自由支持向量等边界，说明适用条件，勿无条件套式。

第 06 周仅 MAXNET：用途是 Winner-take-all（胜者全得）选择最大输入对应单元；结构为对角线 +1、非对角线 −w。使用现有笔记约定 0<w<1/m，非负初始活动，同步更新：
a_i(t+1)=max(0, a_i(t)−w·Σ_{j≠i}a_j(t))。
给出从初始向量到停止的逐轮计算表；每轮所有节点用同一旧向量，负值截为零。解释唯一最大、并列最大及全零输入；区分“赢家索引”与“原始最大数值”，不声称最终活动仍等于原输入。说明连接权重固定、这是状态迭代，不是每轮学习权重。
主课件实际第 165 页将负连接误称 self inhibitory；现有教材已以该页上下文与 Lippmann 原文核正为 lateral inhibition。保留这一准确说明，必要时复核 course_files_export/ASSPM-Lippmann1987.pdf 实际第 5–6 页及 Box 2。

四-A、最新重点：构建函数、微分与线性代数

安排一个可按需回看的“解题工具”复习块，只补足本课实际需要的数学，不另开一门高等数学课：
- 标量、向量、矩阵的维度，内积、矩阵乘法、转置，以及用矩阵表示一组多元一次方程。
- 线性变换与仿射变换的区别：带非零偏置的映射不能不加限定地称为线性变换；显式非线性特征映射也不是对原输入作普通线性变换。
- 一元求导、偏导/梯度、链式法则、平方误差和二次型求导；二次型公式须说明矩阵对称等适用条件。每一步写明对谁求导、哪些量视为常数。
- 无约束驻点、最小值与最大值的区别；约束问题要连同可行性与 KKT 检查。不能把“导数为零”直接等同于最大值、最小值或全局最优。
- 消元、增广矩阵、初等行变换和回代；在具体小系统中说明唯一解/无解/无穷多解的判断。不要把求逆作为唯一求解办法，不只写一行 A⁻¹b，也不要以黑盒软件代替手算步骤。

计算题采用统一的可见解题路线：识别已知量与未知量 → 写预测/判别函数 → 明确要最小化或最大化什么 → 写目标及约束 → 求导或列最优性条件 → 代数消元 → 写矩阵系统 → 求解 → 回代并解释结果。按题型使用必要步骤，MAXNET 的状态迭代不硬套可微优化流程。
在相关模型处明确比较：SVM 最大化几何间隔与规范化后最小化权重范数的关系；原始问题最小化与对偶问题最大化的变量和约束分别是什么；MAXNET 选择最大输入索引与优化模型参数是不同任务。这些练习用于澄清“最高/最大”的可能含义，不宣称已确定老师指的是其中某一种。

四-B、最新重点：LS-SVM 从建模到线性方程组

以第 05 周 #ls-primal、#ls-derivation、#ls-example 为回归主线，并对照 #ls-sparsity 的分类形式。完整覆盖：
1. 从题设识别分类/回归、标签含义、训练数据、核、正则化参数和待求变量，写出预测函数。
2. 解释为什么构建“权重范数惩罚＋平方误差”的目标，明确是最小化；写出等式约束，说明等式中允许残差，并不代表预测必须穿过所有样本。
3. 按同一符号约定构建 Lagrangian（拉格朗日函数）。依次对权重、偏置、残差和等式乘子求偏导，展示消元过程，不跳过中间式。
4. 将标量条件整理成分块线性系统，逐块解释行列维度、单位矩阵、全 1 向量或标签向量的位置。未知量排序可以不同，但行列及右端必须同步变化。
5. 至少一个完整回归算例：从两个或三个训练样本算核矩阵，组装包含偏置的方程组，展示增广矩阵/高斯消元，解出系数及偏置，预测新点，再检查残差与最优性条件。
6. 至少一个小型分类对照算例：突出带标签核矩阵、标签所在位置、残差含义和最终 sign 判别；不能把分类系统与回归系统的右端或系数混用。新消息未限定分类/回归，二者均需辨认。
7. 至少一道换数据或参数的迁移题，以及一道“找出推导/矩阵中的错误”的纠错题，完整解析默认折叠。能够从头构建，不能只靠记住最后一个矩阵。
8. 解释为什么固定有效核、正正则化参数等条件重要，如何判断求解是否合理；标准 LS-SVM 通常稠密，等式乘子不必非负，不能照搬标准 SVM 的盒约束。不要把“解线性方程组”误说成原始目标不是二次优化。

四-C、最新重点：模型特性、区别、共性和关键词简答

用“关键词 → 关键词的准确含义 → 可写在答卷上的短回答”组织练习。先让学生自己作答，再展开示范；示范答案是复习训练材料，不冒充官方评分标准。
每道比较题给出共同点、比较维度明确的不同点、适用任务和限制；不要只罗列名词或泛泛回答“都是神经网络/机器学习”。根据题目用几句完整句子作答，答案之后再列关键术语便于自查。
至少安排这些有课程依据的比较：
- M-P / Perceptron：阈值判定的联系、手工设计与学习、veto 与一般加权输入的区别。
- Perceptron / ADALINE：训练误差依据、阈值输出与线性输出、更新方式和表示能力。
- MLP / RBF：隐藏表示、激活的作用、参数训练和任务能力；BP 是训练方法。
- RBF / FLN / ELM：特征如何产生、哪些参数学习、输出层求解的联系。
- RBF network / RBF-kernel SVM：共同使用径向相似性，但模型结构、目标、中心/支持向量和训练方式不同。
- Hard-margin / Soft-margin SVM：可分性前提、松弛和 C、支持向量与约束。
- SVM / SVR / LS-SVM：任务、输出、损失、约束、求解与稀疏性；注明 LS-SVM 也有分类形式，不能简单写成“SVM 分类而 LS-SVM 回归”。
- MAXNET 与前馈预测模型：状态循环、固定连接、竞争选择、输出的含义。比较止于既定期中范围，不引入 ART/SOM 的算法问题。
同时保留监督/无监督、线性/非线性、训练/推理、表示/优化/泛化等跨模型辨析。关键词必须附一句准确解释，并配一项任务判断或比较例题。

逐项检查考试范围、模型对照表、知识点覆盖、每块至少一个折叠例题、索引和完整笔记链接；不遗漏后半段的 SVR、LS-SVM 和 MAXNET。另按最新消息验收：LS-SVM 建模→求导→消元→矩阵求解→回代链条完整；分类/回归有明确对照；微分和线代有实际算例；简答同时覆盖特性、区别、共性和中英文关键词；“最高/最大”的歧义未被擅自写成确定考题。
本地运行原有构建/内容检查/浏览器检查，并为专题加入必要验收：桌面/手机、浅深主题、折叠、全部展开、打印、中文/英文搜索、答案搜索、章节跳转与刷新、回到原笔记、独立进度保存、控制台及资源 404。
继续使用正式仓库子路径验证，检查旧十二周页面没有回归；不要通过删除原检查来适配新页面。更新 README 中专题的更新与发布方法。

我授权将本任务必要的网站变更提交并推送到现有 yqia03/cs5486-learning-notes，使用既有 GitHub Actions 和 Pages 发布，无需再次询问是否上线。先检查登录及远端，保留用户已有改动，精确暂存，不强推。
等 Actions 成功，打开实际 /midterm/，测试首页入口、例题展开、搜索和返回原笔记的深层链接；验证通过后才报告完成。身份或权限阻塞时只说明所需最小人工步骤，不向聊天索要密码或 token。
